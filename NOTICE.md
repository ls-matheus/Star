# Source provenance and third-party notices

Star integrates multiple source components with independent histories. This notice helps readers distinguish the integrated repository from the origins of those components.

## Component origins

The existing [Docker integration documentation](Docker/README.md) identifies the Star Web/Server code as derived from the [Fluxer project](https://github.com/fluxerapp/fluxer) and references the [Fluxer Flutter client](https://github.com/fluxerapp/flutter_client) and [Fluxer Dart SDK](https://github.com/fluxerapp/dart_sdk) as component origins.
