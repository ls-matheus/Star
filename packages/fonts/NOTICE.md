# Font licences

The WOFF2 files in `files/` are Modified Versions of IBM Plex, except
`files/StarSansBengali/`, which holds Modified Versions of Noto Sans Bengali.

IBM Plex is licensed under the SIL Open Font License, Version 1.1, reproduced in

## Modifications

Clause 3 of the licence reserves the name "Plex", so these Modified Versions do
not present it. The family, full, PostScript and typographic-family name records
were changed:

| Original | Modified Version |
| --- | --- |
| IBM Plex Sans | Star Sans |
| IBM Plex Mono | Star Mono |
| IBM Plex Sans Arabic | Star Sans Arabic |
| IBM Plex Sans Devanagari | Star Sans Devanagari |
| IBM Plex Sans Hebrew | Star Sans Hebrew |
| IBM Plex Sans Thai Looped | Star Sans Thai Looped |
| IBM Plex Sans JP | Star Sans JP |
| IBM Plex Sans KR | Star Sans KR |
| IBM Plex Sans SC | Star Sans SC |
| IBM Plex Sans TC | Star Sans TC |

The `gasp` table was normalised, and the JP, KR, SC and TC families were split
into subsets. The copyright, licence, trademark, manufacturer, designer and
vendor name records are unchanged.

## Noto Sans Bengali

The files in `files/StarSansBengali/` are Modified Versions of Noto Sans
Bengali 3.011 from the Noto Project.

Copyright 2022 The Noto Project Authors.

Noto Sans Bengali is licensed under the SIL Open Font License, Version 1.1,
reproduced in `LICENSE-NOTO-SANS-BENGALI.txt`. That licence accompanies these
files and applies to them.

The hinted TrueType files were converted to WOFF2 and the `gasp` table was
normalised. The family, full, PostScript and typographic-family name records
were changed from Noto Sans Bengali to Star Sans Bengali. The copyright,
licence, trademark, manufacturer, designer and vendor name records are
unchanged.
